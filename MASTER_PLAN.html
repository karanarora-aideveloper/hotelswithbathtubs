Hotels With Bathtubs — Master Plan

Written 24 Oct 2026 · Status key: DONE (in code, not deployed) · RUNNING · NEXT · DECIDE (needs the owner) · Nothing in this plan has been deployed to Cloudflare yet.

Rules we agreed
  • No deploy until everything is closed. Order before deploy: type-check, lint, test build, then you approve.
  • Iteration = I fix all cities, then you test one random city. Whenever you say "random", I pick exactly one.
  • A link is kept only if the page it opens names the same hotel in the same city. Otherwise it is emptied, never replaced with a search page.
  • No tools that bypass bot protection. No paid services unless you say so.
