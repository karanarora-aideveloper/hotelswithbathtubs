Where we are today

Part 1 — Build and deploy on Cloudflare's cloud

Goal: your Mac stops building and uploading. You push code, Cloudflare builds the site on its own machines and publishes it. Every branch also gets a private preview address, so you can approve before anything reaches the public site.

Decision 1.1 — How does the cloud build get the hotel data?

OptionHow it worksGoodWatch out
A. Data snapshot in R2I save today's hotel and blog data as one file in your existing R2 storage. The cloud build downloads it. No database password goes to Cloudflare.Safe, fast, repeatable, nothing to open on MongoDB.Data changes need one command to refresh the snapshot before a build.RECOMMENDED
B. Snapshot committed to GitThe same file lives in the code repository.Simplest, nothing outside Git.A 9 MB data file in the repository; each data update becomes a commit.
C. Cloud build reads MongoDB directlyThe database password is added to Cloudflare, and MongoDB Atlas must accept connections from anywhere.No snapshot to maintain.Opens your database to the whole internet and puts its password in the build settings. A flaky connection already broke one of our builds.

Part 2 — Luxury redesign (home page and whole site)

Goal: one consistent luxury look. Today the site mixes three colour systems and five fonts, plus an unfinished ivory-and-bronze attempt. Booking buttons, click tracking, page addresses, headings and structured data stay exactly as they are, so Google rankings and revenue are not put at risk.

Decision 2.1 — Style direction

OptionFeelColours and type
A. Ivory and gold, editorialWarm, calm, boutique-hotel magazine. Large photos, plenty of space.Ivory background, charcoal text, one soft gold accent. Serif headlines (Playfair Display), quiet sans for text.RECOMMENDED
B. Midnight spa, darkDramatic, immersive, evening mood. Photos glow against dark.Deep charcoal and near-black, gold accents, light text. Serif headlines.
C. Modern minimalCrisp, gallery-like. Thin lines, very large photography.White and black, one bronze accent, a refined sans for headlines and text.

Option A fits "bathtub" best (warm, relaxing) and is closest to the ivory-and-bronze pieces already in the code, so it is the least work and the least risk. Option B reads as "premium" but is harder to keep readable on hotel photos and costs more work. You can also hand me mock-ups from Google Stitch and I will build to them.
